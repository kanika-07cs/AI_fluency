LLM vs LLM + External Tool

Student Attendance Assistant

Scenario

The college maintains student attendance records in an external attendance notice.

A plain language model does not automatically have access to this information.

Student ID Student Attendance
23CS101 Kanika 87%
23CS102 Arun 76%
23CS103 Priya 92%
23CS104 Rahul 81%

1. Plain LLM

No external tool is available.

Question

What is the current attendance of student 23CS101?

Limitation

The LLM cannot access the current attendance notice by itself.

It should not guess the student's attendance.

2. LLM + One Tool

The LLM has access to one external tool:

read_attendance_notice()

Reads the attendance notice and returns its visible information.

Result:

What is a Tool?

A tool is an external function that provides the LLM with information or capabilities that are not available from its own trained knowledge.

What is a Tool Call?

A tool call is a structured request from the LLM asking the application to execute a specific external function.
